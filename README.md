# Veai × Ростелеком — материалы для обсуждения

Статические HTML-колоды, распространяются по ссылке. Навигация: стрелки ← →, свайп, номер слайда в адресе (`#3`). Печать в PDF: Ctrl+P, формат 1280×720.

- `clean/` — объяснительная записка (без цифр)
- `numbers/` — версия с цифрами и источниками
- `strategy/` — ИИ-стратегия Ростелекома на 12 месяцев, видение «с чистого листа» (черновик для обсуждения): три варианта структуры, у каждого два вида карты активов — `1-blank/`, `1-hypothesis/`, `2-blank/`, `2-hypothesis/`, `3-blank/`, `3-hypothesis/`
- `kii/` — ИИ для критической информационной инфраструктуры (черновик для обсуждения): вариант A — гибрид (`a-blank/`, `a-hypothesis/`), вариант B — как Veai вписывается в стратегию (`b/`)
- `vtb-operator/` — оператор ИИ-разработки рядом с банком, материал для ВТБ: версия A «Зачем + оператор» (`vtb-operator/`, PDF — `operator-a.pdf`) и версия C «Внутри или рядом» (`vtb-operator/choice.html`, PDF — `operator-c.pdf`)
- `kii-agent-pitch/` — ИИ-агенты для КИИ: зачем агенты, доказанное ядро, цикл ADLC, место Veai (срез 02.10.2026); PDF — `kii-agent-pitch/ai-agents-kii.pdf`
- `vtb-stack/` — карта стека ИИ-разработки для ВТБ, с 07.10.2026 — с вкладкой 5 «Китай»: on-prem ландшафт КНР и банки Китая как образец (`vtb-stack/#cn`); `vtb-stack/builder/` — конструктор программы на этой карте; `vtb-stack/builder-v2/` — конструктор ИИ-трансформации, версия 2 (проекты ВТБ)
- `vtb/` — оглавление материалов для ВТБ: что для чего и в каком порядке читать
