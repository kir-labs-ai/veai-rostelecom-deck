# Veai × Ростелеком — материалы для обсуждения

Статические HTML-колоды, распространяются по ссылке. Навигация: стрелки ← →, свайп, номер слайда в адресе (`#3`). Печать в PDF: Ctrl+P, формат 1280×720.

- `clean/` — объяснительная записка (без цифр)
- `numbers/` — версия с цифрами и источниками
- `strategy/` — ИИ-стратегия Ростелекома на 12 месяцев, видение «с чистого листа» (черновик для обсуждения): три варианта структуры, у каждого два вида карты активов — `1-blank/`, `1-hypothesis/`, `2-blank/`, `2-hypothesis/`, `3-blank/`, `3-hypothesis/`
- `kii/` — ИИ для критической информационной инфраструктуры (черновик для обсуждения): вариант A — гибрид (`a-blank/`, `a-hypothesis/`), вариант B — как Veai вписывается в стратегию (`b/`)
