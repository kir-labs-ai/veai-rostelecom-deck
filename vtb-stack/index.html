Вариант 1 · стек без привязки к компаниям

Агенты — только верхний этаж. Чтобы банк внедрил их целиком внутри контура, ему нужны все 12 этажей от железа до агентов и 5 сквозных слоёв: выпадет хоть один — контур не закрыт.

Задача стека: дать банку агентную разработку (агенты пишут, тестируют и переносят код) и агентов в процессах банка (эксплуатация, бэк-офис, поддержка, аналитика) — так, чтобы железо, модели, данные и журнал действий оставались у банка.

  1. 1Ничего внешнего. Железо, модели, данные и журналы — в ЦОД банка. Облачные сервисы и внешние API исключены.
  2. 2Модели свои. Открытые веса, развёрнутые у банка и прошедшие допуск как модельный риск. Облачные API моделей, включая Anthropic, не используются.
  3. 3Claude Code — только как локальный харнес. Ставится у банка, обращается к внутреннему инференсу через шлюз, внешний трафик отключён. Оговорка: работу Claude Code с не-Claude моделями Anthropic официально не поддерживает — каждое обновление проверяется на стенде банка.

С чего начинать сборку

Слои строятся не все сразу. Порядок ниже снижает риск: сначала фундамент и один измеримый сценарий, потом тираж.

Шаг 1 · фундамент

Этажи 1–5 + безопасность и управление автономией. Железо, пул вычислений, инференс, первые модели и шлюз. Без шлюза нельзя начинать: он даёт единую дверь к моделям, учёт и журнал с первого дня.

Шаг 2 · пилот агентной разработки

Этажи 7, 8, 10, 11 + сценарии разработки на этаже 12. Индекс кода, связь с Git, CI и трекером, харнес и плагины IDE — на одном домене и одной команде, с внутренними бенчмарками до и после. Разработка — самый быстрый путь к измеримому эффекту: код, тесты и ревью уже оцифрованы.

Шаг 3 · агенты в процессах банка

Этажи 6, 8, 9, 11 + остальные сценарии этажа 12. Обезличенные данные, адаптеры к АБС и шинам, агентная платформа, чат для сотрудников — и выход за пределы разработки: эксплуатация, бэк-офис, поддержка, аналитика.

Что сознательно не входит в стек облака, внешние API, SaaS — и почему
  • Публичные облака и облачные сервисы ИИ — противоречат условию «всё внутри контура», даже если провайдер обещает изоляцию.
  • Облачные API моделей (Anthropic, OpenAI и аналоги) — данные и код уходят за периметр. Их место занимают открытые модели на этаже 4.
  • SaaS-инструменты для агентов, интеграций и наблюдаемости — только версии, которые ставятся в ЦОД банка.
  • Anthropic допустим в одной роли — Claude Code как локальный харнес на этаже 10, который работает с внутренним инференсом через шлюз.
  • «On-prem» у вендора ещё не значит «без сети». Лицензии, телеметрия и обновления часто требуют выхода наружу — каждый компонент проверяется пилотом с полностью закрытым выходом.
